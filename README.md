# SignalForge AI

Русскоязычное веб-приложение для визуального разбора скриншотов торговых графиков с серверным подключением vision-модели через OpenAI Responses API.

## Что умеет
- Загрузка и перетаскивание PNG/JPG/WEBP до 12 МБ, предпросмотр и замена файла.
- Горизонт анализа от 3 секунд до 3 дней.
- Отправка изображения на сервер и анализ vision-моделью `gpt-4.1-mini` (можно изменить через `OPENAI_MODEL`).
- Структурированный результат: сигнал, субъективная уверенность модели, причины и оговорка о рисках.
- История текущей сессии и адаптивный тёмный интерфейс.
- API-ключ хранится только в переменной окружения сервера, не в браузере.

## Запуск локально
Требуется Node.js 20+ и OpenAI API key с доступом к выбранной модели и доступным API-биллингом.

1. Создайте API key в кабинете OpenAI.
2. Установите переменную окружения `OPENAI_API_KEY` (не вставляйте ключ в `index.html` и не публикуйте его).
3. При необходимости задайте `OPENAI_MODEL=gpt-4.1-mini`.
4. Запустите `npm start`.
5. Откройте `http://localhost:3000`.

Пример для macOS/Linux:
```bash
export OPENAI_API_KEY="ваш_ключ"
npm start
```
PowerShell:
```powershell
$env:OPENAI_API_KEY="ваш_ключ"
npm start
```

Проверка статуса API: `GET /api/health`. Без настроенного ключа анализ вернёт понятную ошибку и не будет выдавать фиктивный сигнал. При деплое задайте `OPENAI_API_KEY` в разделе Secrets/Environment Variables хостинга.

## Важно
Это визуальный разбор изображения, а не надёжный прогноз цены. Модель может ошибаться при чтении шкал, свечей и индикаторов. Уверенность означает субъективную уверенность в интерпретации, а не вероятность прибыли. Скриншот не заменяет актуальные котировки, проверку рынка и управление рисками. Не используйте результат как единственное основание для сделки.
